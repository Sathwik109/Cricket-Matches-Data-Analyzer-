
# Cricket Matches Survey Analysis (C++)

A C++ command-line analytics application that dynamically processes athletic survey data from up to 5,000 respondents.

## Features
- **Dynamic Memory Allocation:** Allocates and frees heap memory at runtime based on survey sample size.
- **Statistical Operations:** Computes respondent averages (mean) and detects max match frequency.
- **Data Ordering:** Implements in-place Selection Sort to sort paired parallel records alphabetically by student name.

## Build & Run
```bash
make
./survey_analyzer
